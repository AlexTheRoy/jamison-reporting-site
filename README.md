# Jamison Agency Reporting Site

Static client reporting site for Jamison Agency (GOAL account #601), deployed on Vercel.

- `index.html`: hub with Campaign Reports and Website & Research
- `Jamison-*-YTD-10-15-26.html`: campaign reports, year to date
- `Jamison-Inbound-Call-Review-10-15-26.html`: inbound calls, Jul 17 to Oct 15, 2026
- `Jamison-SEO-Audit-10-15-26.html`, `Jamison-TX-*`: website audit and Texas research
- `vercel.json`: clean URLs, security headers, noindex

No build step. Push to `main` and Vercel redeploys.
